# T-Bank storage — mdtask

## Хранение продаж

Для успешных карточных продаж Т-Банк сохраняется номер ссылки операции.
Путь к SQLite-базе задаётся переменной <code>tbank_sql_path</code> в локальном
<code>.env</code>; пример значения находится в <code>.env.example</code>.

При возврате исходная продажа ищется в этой же базе по дате и номеру чека
СБИС. Найденный RRN передаётся терминалу автоматически; при отсутствии записи
или ошибке базы сохраняется ручной ввод.

  Ошибку записи логировать, не изменяя результат уже успешной оплаты.

  - Ошибки SQLite логируются и не меняют результат банковской операции.
