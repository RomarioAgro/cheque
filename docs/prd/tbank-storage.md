# T-Bank storage — mdtask

## Хранение продаж

Для успешных карточных продаж Т-Банк сохраняется номер ссылки операции.
Путь к SQLite-базе задаётся переменной <code>tbank_sql_path</code> в локальном
<code>.env</code>; пример значения находится в <code>.env.example</code>.
