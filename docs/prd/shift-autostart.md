# Автоматическое открытие смены — mdtask

## Автозапуск смены

Для открытия смены запустить `operation_shtrih.py` с JSON, содержащим
`operationtype: open_shift`, `tag1021` и `tag1203`. Команду можно добавить в
Планировщик заданий Windows. Уже открытая смена повторно не открывается, а ошибка
связи или неподходящий режим кассы завершают процесс с ненулевым кодом.

При закрытой смене программа обновляет локальный список сотрудников и запрашивает
код кассира в консоли. Ошибка обновления допускает использование локального файла.
Смена открывается только для уникального кассира с заполненными корректными ИНН и
при совпадении ИНН работодателя с регистрационным ИНН ККТ.
